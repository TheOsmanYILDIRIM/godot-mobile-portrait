# Godot 4 Mobile Portrait Editor - Proje Kuralları

Bu proje Godot 4 için dikey mobil ekran editör arayüzü ve eklentisidir.

## Kurallar
- GDScript dosyalarında static typing ve `@tool` annotasyonu kullanılmalıdır.
- Termux ortamında yerel Gradle veya SCons C++ derlemesi yapılmamalı, `.github/workflows/` kullanılmalıdır.
- UI bileşenlerinde dokunma hedef boyutu minimum 44-48dp olmalıdır.
